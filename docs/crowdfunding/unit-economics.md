# Unit economics worksheet — methodology, no invented figures

Capture three scenarios: conservative, baseline and optimistic, each at 10/100/1000 units or supported supplier MOQ.

| Input | Unit | Evidence required |
|---|---|---|
| SoC, RAM, PMIC, PHY, connectors | per board | dated BOM/distributor quotations |
| PCB stackup, fabrication, stencil | per batch / unit | fabricator quote |
| SMT/BGA assembly, X-ray, rework | per unit | EMS quote |
| test time, fixture amortization, yield/scrap | per unit | pilot data/quote |
| enclosure, cooling, PSU and packaging | per unit | vendor quote |
| inbound transport, duties, taxes | per unit | shipment assumptions |
| platform/payment fees | per pledge | published fee schedule |
| fulfillment, reserves, support, returns, warranty | per unit | carrier / service estimates |
| one-time NRE, compliance, tooling | fixed | vendor quote |

Define: **net contribution = pledge revenue excluding remitted taxes – all variable costs and fees – allocated contingency**. Fundraising target must additionally cover NRE, campaign costs and cash-flow timing. Do not mistake BOM cost for landed retail cost.

Version every estimate and retain vendor quote validity dates and currencies.
