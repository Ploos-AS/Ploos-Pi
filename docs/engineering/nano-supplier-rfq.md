# Nano supplier RFQ / technical enquiry

Subject: Bare ARM64 SoC engineering documentation and volume procurement enquiry

Ploos AS is evaluating an original ARM64 single-board computer for headless Linux compute nodes. We seek **bare semiconductor components**, not compute modules or carrier boards.

Please identify:
1. Exact orderable part numbers, package variants, lifecycle and availability.
2. Authorized distribution channels, MOQ and indicative price breaks at 10/100/1000 units; quote currency, validity and lead times.
3. Public or NDA hardware documentation: pinout, DDR layout and signal-integrity guide, power/PMIC sequencing, reference schematics, errata and package land pattern.
4. Supported boot modes, recovery and Linux/U-Boot source availability, required binary components and redistribution terms.
5. Recommended PHY/eMMC/RAM configurations and any verified reference designs.
6. Evaluation samples and technical support for first-time BGA board bring-up.
7. Product change notifications and longevity commitments.

Please mark materials confidential where applicable. We will not publish NDA content without permission.

**No purchasing commitment or production volume is implied by this enquiry.**
