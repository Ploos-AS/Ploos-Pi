# Licensing intent and third-party rights

- Hardware designs, schematics, layouts and HDL: **CERN-OHL-P-2.0** (intended).
- Original project software and firmware: **MIT** (intended default).
- Original documentation: **CC BY 4.0** (intended).

This file describes the project licensing policy; **a full SPDX-compliant license-text package, file headers and third-party inventory remain M0 tasks**. No copyright or patent rights from SoC vendors are implied. Third-party firmware, IP blocks, fonts, logos, bootloaders and datasets retain their own licenses; redistribution must be reviewed before publication.

Use SPDX identifiers and a REUSE-style inventory before first hardware/firmware release. Verify compatibility and source obligations for all delivered binaries and toolchains.
